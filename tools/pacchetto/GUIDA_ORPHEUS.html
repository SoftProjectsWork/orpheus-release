Prima volta

Installare ORPHEUS

Circa 5 minuti. Il pacchetto pesa 67 MB e contiene il programma e Python.

  1. Scarica lo zipDalla pagina Releases del repository pubblico scarica ORPHEUS_<versione>_windows.zip.
    github.com/SoftProjectsWork/orpheus-releaseReleases › Latest › Assets
  2. Estrai tuttoTasto destro sullo zip › Estrai tutto…. Non lanciarlo da dentro lo zip.
  3. Doppio clic su installa.cmdSe compare Windows ha protetto il PC: Ulteriori informazioni › Esegui comunque.
  4. Rispondi a due domande
    Cartella dei datiInvio = C:\ORPHEUS_DATILa tua e-mailper Crossref e OpenAlex, resta sul PC
Alla fineSul desktop trovi l'icona ORPHEUS: apre il cruscotto nel browser. I comandi sono in C:\ORPHEUS. La cartella estratta dallo zip si può cancellare.
Ogni nuova versione

Aggiornare

Un doppio clic. Serve internet. I tuoi dati non vengono toccati.

  1. Chiudi ORPHEUSChiudi la finestra del cruscotto e gli altri comandi aperti.
  2. Doppio clic su aggiorna.cmdIn C:\ORPHEUS. Controlla su GitHub l'ultima versione.
    ORPHEUS installato: versione 0.54.1Ultima versione pubblicata: …
  3. Scarica e installaSe c'è una versione nuova la scarica e la installa da sola. Se no scrive Hai già l'ultima versione.
  4. Database aggiornatoSe la struttura cambia, prima fa una copia di sicurezza in C:\ORPHEUS\locale.
Tra colleghi

Condividere le schede

Un file .zip passa da un PC all'altro. Vale per ORPHEUS ed EURYDIKE: nel menu di entrambi c'è Condivisione.

ORPHEUSEURYDIKE

Chi manda

  1. Cruscotto › Condivisione
  2. Crea il file per i colleghi
  3. Mostra nella cartella (o Scarica)
ORPHEUS_condivisione_<data>.zip mail, chiavetta o cartella condivisa · circa 25 MB

Chi riceve

  1. Cruscotto › Condivisione
  2. Scegli il file .zip del collega
  3. Guarda la prova, poi Importa adesso
Quello che hai già resta tuoLo stesso articolo (DOI), la stessa rivista (ISSN), lo stesso PDF non cambiano. Una scheda arriva solo se tu non ce l'hai. Prima dell'unione c'è sempre una copia di sicurezza. Importare due volte lo stesso file non aggiunge nulla.
Il file contiene testo di articoli non apertiMandalo solo a colleghi con gli stessi accessi agli articoli. Mai su internet, mai su GitHub.

Senza cruscotto: esporta_schede.cmd e importa_schede.cmd in C:\ORPHEUS (si può trascinare lo zip sopra importa_schede.cmd).

Dove stanno le cose

├─ cruscotto.cmd           apre il cruscotto

├─ esporta_schede.cmd
├─ importa_schede.cmd
├─ registri\               un file per comando

│  └─ condivisione\        file ricevuti
└─ condivisione\           file creati da te

Se qualcosa non va

Un comando dà erroreIl dettaglio è in C:\ORPHEUS\registri; l'installazione in C:\ORPHEUS\installazione_log.txt.
La ricerca per significato non parteInstalla Microsoft Visual C++ Redistributable (x64) dal sito Microsoft, poi riprova.
Le verifiche online non partonoManca l'e-mail: aggiungi ORPHEUS_CONTACT_EMAIL=… in C:\ORPHEUS\orpheus\.env.
